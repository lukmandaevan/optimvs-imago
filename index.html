Measurement workflow

OPTIMVS is designed to make every image-quality measurement explicit. A recommended research workflow is:

  1. Load the planar image or complete CT series, or click Call synthetic CT phantom to open the built-in educational dataset.
  2. Verify pixel spacing, slice spacing, rescale slope/intercept, and displayed orientation.
  3. Choose an analysis method appropriate to the phantom and task.
  4. Place ROIs prospectively and consistently.
  5. Inspect intermediate plots, not only the reported summary number.
  6. Record the result and export the full table for statistical analysis.
  7. Validate the workflow against an independent reference before scientific or clinical use.
For CT with iterative or nonlinear reconstruction, task-based measurements such as TTF, NPS and d′ are generally more informative than a single high-contrast resolution number.

Built-in synthetic CT phantom

The phantom is generated entirely in the browser and contains four deliberately separated structures:

  • Slanted high-contrast edge for 2D MTF.
  • Small 3D bead for volumetric point-spread/3D MTF.
  • Low-contrast cylindrical insert for TTF.
  • Large homogeneous region for 2D or 3D NPS.

OPTIMVS IMAGO also creates demonstration ROIs automatically so the learner can immediately explore each calculation.

Modulation Transfer Function

MTF describes how spatial frequencies are transferred by the imaging system. Values are normalized to unity at zero spatial frequency.

MTF(f) = |FFT{LSF(x)}| / |FFT{LSF(x)}|f=0

2D edge method

  1. Choose a sharp, high-contrast edge.
  2. Draw a rectangular ROI spanning both sides of the edge.
  3. OPTIMVS estimates edge orientation and constructs an oversampled edge-spread function (ESF).
  4. The derivative of the ESF gives the line-spread function (LSF).
  5. The Fourier transform of the LSF gives the MTF.

3D bead / point method

  1. Load a CT stack with a small high-contrast bead or point object.
  2. Place a compact ROI around the bead on its central slice.
  3. Select a slice range covering the complete point-spread function.
  4. OPTIMVS extracts the 3D PSF, subtracts background, calculates a 3D FFT, and radially averages the normalized spectrum.

Noise Power Spectrum

NPS characterizes not only noise magnitude but also its spatial-frequency distribution. Two images may have identical pixel SD but very different texture.

NPS(fx,fy) ∝ ΔxΔy / N · |FFT{I(x,y) - trend(x,y)}|²
  1. Choose a homogeneous region free from edges or objects.
  2. Draw a rectangular uniform ROI.
  3. Remove the mean or fitted low-frequency plane.
  4. Apply the FFT and scale by pixel dimensions.
  5. Inspect both the 2D NPS map and radial one-dimensional profile.

For CT, 3D NPS additionally incorporates the slice direction and requires a sufficiently homogeneous volume.

Task Transfer Function

TTF is analogous to MTF but is measured using an object whose contrast resembles the clinical task. This makes resolution characterization sensitive to object contrast and reconstruction nonlinearity.

  1. Select the target insert using a circular object ROI.
  2. Select a representative background ROI.
  3. OPTIMVS estimates the object centre and builds a radial edge-spread profile.
  4. The radial ESF is differentiated to obtain an LSF.
  5. The normalized Fourier magnitude yields TTF.
The object should be sufficiently large to define a stable radial edge while remaining representative of the task contrast being studied.

Detectability index d′

d′ combines a task function, system transfer function, and noise spectrum into a single task-based detectability metric.

d′² ≈ 2π ∫ |Wtask(f) · T(f)|² / [NPS(f) + Ninternal] · f df
  1. Calculate TTF or MTF for the same protocol.
  2. Calculate NPS from a homogeneous region acquired/reconstructed consistently.
  3. Define object size and contrast.
  4. Choose the task model.
  5. Calculate d′ and inspect the frequency contribution plot.

The numerical d′ depends on the exact observer model, task normalization, NPS scaling and dimensional assumptions. OPTIMVS therefore displays the implementation transparently and should be independently validated before publication.
